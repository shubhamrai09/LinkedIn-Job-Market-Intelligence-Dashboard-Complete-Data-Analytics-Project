# 📊 LinkedIn Job Market Intelligence Dashboard
# End-to-End Data Analytics Project

An end-to-end Data Analytics and Business Intelligence project that analyzes LinkedIn job-market data to identify hiring trends, top hiring companies, job locations, work types, experience levels, and the most in-demand technical skills.

The project demonstrates a complete analytics workflow using Excel, SQL, Python, and Power BI, starting from raw data cleaning and ending with an interactive business intelligence dashboard.

# 📌 Project Overview

The objective of this project is to transform raw job-posting data into meaningful insights that can help understand the current job market.

The analysis focuses on questions such as:

Which companies are hiring the most?
Which locations have the highest number of job opportunities?
What are the most in-demand skills?
What percentage of jobs are On-site, Hybrid, Remote, or Contract?
Which experience levels are most frequently requested?
How many jobs and companies are represented in the dataset?
What does the overall job market look like?
